# 制作说明

## 视频目标

面向领导介绍江苏省监测技能竞赛在线答题系统。先说明赛前测试与赛中正式环境，以及技术端、评委端和选手端三个系统；再依次介绍技术系统、选手接入大模型 API，以及评委出题和选手答题的完整流程。

## 内容定位

- 本片是系统介绍，不是测试情况汇报。
- 旁白介绍系统如何使用，以及三个系统如何协同。
- 总起说明系统覆盖赛前测试和赛中正式环境。
- 技术系统只用两个短镜头说明创建账号和多路模型服务保障。
- 选手获取凭证后，可把 API 接入自己的知识库完成赛前调试。
- 不使用“本次测试、测试结果、达到预期、上线复测”等表述。
- 不讲组网、部署拓扑和底层技术实现。

## 当前阶段

- 已按照定稿脚本重新生成 4 个独立章节和完整成片。
- 完整版时长约 3 分 38 秒，规格为 1920 × 1080、30 fps、H.264 + AAC。
- 旁白使用 `Tingting`，语速为 165，按完整镜头段落生成。
- 视频包含内嵌字幕，并提供独立 SRT 字幕文件。
- 技术端账号创建画面未展示已有账号列表中的密码。

## 章节结构

1. 赛前、赛中与三个系统
2. 技术系统
3. 选手接入大模型 API
4. 评委出题与选手答题

## 叙事规则

- 第一章简要说明赛前、赛中和三个使用端，不重复展开技术端职责。
- 第二章压缩为创建账号和多路服务保障两个短镜头。
- 第三章只说明选手获取凭证、接入自己的知识库并完成赛前调试。
- 第四章按照评委出题、选手接题、保存草稿、最终交卷和评委收卷介绍答题流程。
- 结尾总结三个系统如何共同支撑竞赛，不再增加上线状态说明。

## 画面原则

- 每个镜头只表达一个功能或一个操作结果。
- 关键操作完成后保留足够时间，让领导看清页面反馈。
- 不使用组网拓扑图，不讲公网、局域网、供应商和底层路由。

## 安全约束

- 页面中的密码和 API Key 必须使用演示值或在后期遮挡。
- 不录制真实供应商密钥、环境变量、Cookie 和管理员密码。
- 演示过程只使用可清理的账号、题目和答卷。
