# 选手操作视频精简旁白

本稿对应 01 至 12 共十二个独立镜头。镜头 01 为片头，镜头 02 至 12 按选手实际操作顺序组织。每个镜头只说明一项主要任务、确认结果和必要限制。

## 01 片头

沿用已确认版本。

## 02 赛前设备与离线环境准备

1. 赛前准备比赛电脑、电源、有线鼠标键盘和必要的有线网卡或转接器。建议内存不低于十六 GB、可用磁盘空间不低于一百 GB。
2. 赛前还需在比赛用机准备本地知识库和所需规范资料。要确保除了大模型接口外，其他内容均能够在离线环境下完成启动、运行等操作。比赛现场不提供互联网访问能力。

## 03 登录并获取模型接入信息

1. 按照通知进入赛前测试环境，使用组委会发放的测试账号登录，并核对姓名、账号和测试模式。测试数据不计入正式成绩。
2. 登录后进入 API 技术文档，复制完整 API URL 和本人 API Key。
3. 从可用模型列表直接复制模型 ID，并严格区分大小写。

## 04 配置本地知识库模型服务

1. 以 Cherry Studio 为例：在自定义服务商中填写 API Key、完整 API 地址，并获取或添加允许模型。
2. API Key 仅限本人测试使用，不得共享、公开。正式比赛时，按照比赛现场提供的局域网 API URL 进行替换即可，登录账号密码、API Key、模型 ID 等均与测试环境一致。

## 05 验证本地知识库正常运行

1. 随后在本地知识库中发起一次测试检索，确认资料能够正常召回，并能调用已配置模型生成结果。
2. 如果运行失败，先按状态码检查：四百零一核对凭证，四百核对模型，四百二十九降低频率，五百零三停止调用并报告。

## 06 测试答题环境操作

1. 模型和知识库验证完成后，返回答题工作台。该入口用于接题、作答、保存和提交。
2. 测试模式中完整演练题目读取、答题、附件上传、草稿保存、恢复和提交。
3. 保存后等待页面显示已保存，再切换题目。
4. 最终提交后答案锁定。赛前应确认自己理解这一规则。

## 07 正式比赛登录与纪律

1. 正式比赛只连接组委会指定网络。禁止热点、VPN、代理、外网模型和未经许可的服务。
2. 使用正式账号登录，核对本人信息和比赛模式。正式模式下操作计入比赛记录。
3. 账号、API Key、知识库和答案不得共享；不得代答、查看他人内容或干扰竞赛系统。客户端会按要求记录操作过程。
4. 比赛未开始时保持页面开启。开始后题目自动显示。考核时长九十分钟，请为核验和提交预留时间。

## 08 阅读题目与确定作答范围

1. 收到题目后，先完整阅读题干、材料范围、作答要求和附件。
2. 明确核查对象、可用材料、回答内容和提交形式，再开始检索。

## 09 检索分析与人工核验

1. 先在知识库检索相关规定和具体条款，再使用允许模型辅助梳理线索。
2. 模型输出后，回到原始材料和规范原文逐项核验，并区分已证实、疑似和证据不足。
3. 答案写明问题、证据位置、规范条款、分析过程和结论。

## 10 编辑答案与保存恢复

1. 在我的回答中组织文字、图片和题目允许的附件，并按照题目要求清晰呈现证据链。
2. 上传完成后，核对文件名称和可打开状态。
3. 作答过程中多次保存草稿。等待页面显示已保存后再切换；修改后需要再次保存。
4. 出现本机未保存答案提示时，先核对缓存时间和内容。需要该版本时点击恢复，并再次保存；确认缓存无效时，才选择丢弃。

## 11 最终检查与逐题提交

1. 最终提交前，逐题检查答案、事实数据、引用条款、附件和作答要求。
2. 确认无误后点击最终提交，阅读提示后确认，并等待服务器返回结果。
3. 页面显示已提交并锁定后，该题不能修改或撤回。继续检查和提交其他题目。

## 12 异常报告与关键要求回顾

1. 无法登录、题目未显示、模型持续失败或保存上传失败时，立即停止重复操作并举手报告。
2. 保存或提交结果不明确时，保持当前页面，不连续点击、不切换、不退出、不清除数据。
3. 向现场人员说明发生时间、当前题目、执行操作和页面提示。未经同意不得调整网络、账号或设备。
4. 比赛中使用指定网络，核验材料和依据，及时保存并按要求提交。发生异常立即报告，具体安排以最新通知为准。
