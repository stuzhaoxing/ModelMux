# 系统介绍视频

本目录用于制作“江苏省监测技能竞赛在线答题系统”介绍视频。

## 目录

- `script/`：总脚本、分章节旁白与录制清单
- `assets/`：页面截图、字幕与音频等制作素材
- `chapters/`：可单独播放和替换的章节视频
- `output/`：最终合并成片
- `tools/`：可重复生成章节与成片的本地脚本

## 输出规格

- 画幅：1920 × 1080，16:9
- 帧率：30 fps
- 编码：H.264 + AAC
- 语言：普通话，简洁、非技术化表达
- 安全：不展示真实密码、API Key、会话信息或供应商密钥

制作状态、成片文件和已知现状见 `script/制作说明.md`。
