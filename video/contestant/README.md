# 选手操作说明视频

本目录保存按镜头独立审查的选手操作说明视频。各镜头确认前不合并成片。

全片重构为 01 至 12 共十二个独立镜头。镜头 02 至 12 按“一个镜头只解决一个主要任务”的逻辑组织，旁白校对基准见 `../script/选手操作视频精简旁白.md`。

## 独立镜头

- `shots/01-片头.mp4`：镜头 01，竞赛主视觉、内容范围和赛前观看提醒。
- `shots/02-赛前设备与离线环境准备.mp4`
- `shots/03-登录并获取模型接入信息.mp4`
- `shots/04-配置本地知识库模型服务.mp4`
- `shots/05-验证本地知识库正常运行.mp4`
- `shots/06-测试答题环境操作.mp4`
- `shots/07-正式比赛登录与纪律.mp4`
- `shots/08-阅读题目与确定作答范围.mp4`
- `shots/09-检索分析与人工核验.mp4`
- `shots/10-编辑答案与保存恢复.mp4`
- `shots/11-最终检查与逐题提交.mp4`
- `shots/12-异常报告与关键要求回顾.mp4`

每个独立镜头 MP4 都有同名 SRT 字幕和 JSON 构建信息。`previews/` 中保存每个镜头的三个审查画面。

当前合并预览为 `选手操作说明-完整预览.mp4`，按镜头 01 至 12 顺序生成。独立镜头仍是后续修改和审查的源文件；任一镜头更新后，需要重新生成合并预览。

## 视觉素材

- `source/generated/`：项目专用的设备准备、隔离网络工位和举手报告场景图。
- `source/official/`：Cherry Studio、Dify、LangChain、LlamaIndex、Milvus 的官网或官方文档截图。
- `source/notice-images/`：正式《选手须知》中使用的脱敏答题系统截图。

软件镜头先说明可选工具，再统一以 Cherry Studio 为例演示知识库召回和模型服务配置。官方软件截图只用于说明对应产品，不代表组委会指定必须使用该软件。

所有网页、系统截图和实物图均采用完整缩放：保留原始宽高比和完整四边，标题、内容、字幕使用独立区域。画面允许出现留白，不通过放大或裁剪填满分辨率。

## 生成命令

```bash
node video/tools/build-contestant-shot.mjs 01
node video/tools/build-contestant-remaining.mjs 02
node video/tools/build-contestant-remaining.mjs all
```

单镜头命令会清理该编号的旧输出并重新生成。`all` 会清理镜头 02 至 20 的旧生成文件，再生成镜头 02 至 12；不会清理镜头 01、领导汇报视频、旧章节或素材，也不会合并视频。
