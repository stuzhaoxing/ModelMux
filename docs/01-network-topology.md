# 江苏省监测技能竞赛在线答题系统局域网隔离组网方案

状态：需求确认版  
日期：2026-08-11

## 1. 已确认的网络要求

目标 Mac mini 同时连接两个相互隔离的网络：

1. Mac mini 能访问互联网中的模型供应商 API，例如硅基流动。
2. 局域网电脑能访问 Mac mini 上的江苏省监测技能竞赛在线答题系统。
3. 局域网电脑不能访问互联网。
4. 局域网电脑不能直接获得模型供应商的 API Key。
5. 江苏省监测技能竞赛在线答题系统不直接暴露到公网。

这意味着不能把 Mac mini 和局域网电脑都直接接入普通的上网路由器，否则这些电脑也会获得路由器提供的互联网出口。

## 2. 推荐方案：双网段物理隔离

Mac mini 使用两个内置网络接口：

- Wi-Fi：只负责 Mac mini 访问互联网。
- 有线以太网：只负责江苏省监测技能竞赛在线答题系统隔离局域网。

```text
                         Internet
                             |
                    [现有上网路由器/AP]
                             |
                       Wi-Fi 上联网段
                     DHCP，例如 192.168.1.x
                             |
                         [Mac mini]
                    Wi-Fi: Internet 出口
                    Ethernet: 10.20.0.1/24
                             |
                  [无互联网连接的独立交换机]
                       /              \
              客户端 A                客户端 B
            10.20.0.10               10.20.0.11
            无默认网关                无默认网关
```

关键点是独立交换机不能再连接上网路由器。这样局域网电脑在物理上就没有直接的互联网出口。

数据流为：

```text
客户端 -> Mac mini 有线网口 -> 江苏省监测技能竞赛在线答题系统
                                  |
                                  -> Mac mini Wi-Fi -> 互联网模型 API
```

江苏省监测技能竞赛在线答题系统是应用层代理。局域网电脑不是通过 Mac mini 做通用 IP 转发，而是只调用 Mac mini 上开放的模型接口。

## 3. 所需设备

### 3.1 只有一台有线客户端

客户端可以用网线直接连接 Mac mini 的有线网口。现代网卡通常不需要交叉线。

### 3.2 有多台有线客户端

增加一台普通非网管千兆交换机：

```text
Mac mini Ethernet -> 独立交换机 -> 多台客户端
```

交换机不需要路由、NAT 或互联网功能。

### 3.3 有无线客户端

在独立交换机上连接一个专用无线 AP。可以使用一台备用路由器的 AP 模式，但其 WAN 口必须保持断开：

```text
Mac mini Ethernet -> 独立交换机 -> 独立 AP -> 无线客户端
```

不要让这些客户端连接负责上网的主路由器 Wi-Fi。

## 4. 地址规划

建议为隔离局域网使用一个与现有网络不重叠的网段：

| 设备 | IPv4 地址 | 子网掩码 | 默认网关 | DNS |
| --- | --- | --- | --- | --- |
| Mac mini Wi-Fi | 主路由器 DHCP 分配 | 自动 | 主路由器 | 自动 |
| Mac mini Ethernet | `10.20.0.1` | `255.255.255.0` | 留空 | 留空 |
| 客户端 A | `10.20.0.10` | `255.255.255.0` | 留空 | 留空 |
| 客户端 B | `10.20.0.11` | `255.255.255.0` | 留空 | 留空 |

客户端不填写默认网关是核心限制：它们只知道如何访问同一网段的 `10.20.0.0/24`，不知道如何访问互联网地址。

### 4.1 Mac mini 配置

在“系统设置 -> 网络”中进行以下配置：

1. Wi-Fi 连接现有上网路由器，IPv4 使用 DHCP。
2. 以太网的 IPv4 改为手动。
3. IP 地址填写 `10.20.0.1`。
4. 子网掩码填写 `255.255.255.0`。
5. 路由器和 DNS 均留空。
6. 确认系统默认路由仍然经过 Wi-Fi。

### 4.2 客户端配置

少量客户端建议直接使用静态地址。每台客户端使用不同地址，例如 `10.20.0.10`、`10.20.0.11`，不要填写默认网关和 DNS。

客户端数量较多时再增加独立 DHCP 服务，但 DHCP 不能下发默认网关或公共 DNS。普通家用路由器的 DHCP 往往会自动下发自己作为网关，不适合直接用于这种严格隔离场景。

## 5. 禁止 Mac mini 转发互联网流量

Mac mini 只提供江苏省监测技能竞赛在线答题系统应用服务，不应充当 NAT 路由器。

必须满足：

1. 不开启 macOS“互联网共享”。
2. 不创建 Wi-Fi 和以太网之间的网络桥接。
3. 不配置 NAT 或端口转发规则。
4. IPv4 和 IPv6 转发保持关闭。

在 Mac mini 上检查：

```bash
sysctl net.inet.ip.forwarding
sysctl net.inet6.ip6.forwarding
```

两个结果都应为 `0`。

即使客户端错误地把 `10.20.0.1` 填成默认网关，只要 Mac mini 没有开启转发，它们也不能通过 Mac mini 上网。不过客户端配置仍应将默认网关留空，形成双重限制。

## 6. 江苏省监测技能竞赛在线答题系统服务边界

江苏省监测技能竞赛在线答题系统建议只监听隔离网口：

```text
10.20.0.1:4000
```

局域网客户端使用：

```text
http://10.20.0.1:4000/v1
```

正式环境再增加 HTTPS。管理后台可以只监听 `127.0.0.1` 或仅通过 Tailscale 管理，避免普通局域网客户端获得管理权限。

Mac mini 上发往硅基流动等供应商的请求会使用 Wi-Fi 默认路由。江苏省监测技能竞赛在线答题系统必须配置请求超时、内部 API Key、限流和日志脱敏。

## 7. 两种替代方案

### 7.1 主路由器按设备禁止上网

如果现有路由器支持可靠的 VLAN 和防火墙策略，可以让所有设备接入同一套网络设施，并配置：

```text
客户端 VLAN -> 允许访问 Mac mini 上的答题系统端口
客户端 VLAN -> 拒绝访问 WAN
Mac mini -> 允许访问 WAN
```

这是正规网络环境中的可扩展方案，但依赖路由器具备真正的 VLAN/ACL 能力。普通家用路由器的“家长控制”可能只拦截 DNS 或网页，不等同于完全禁止互联网。

### 7.2 Mac mini 互联网共享

不采用。互联网共享会把 Mac mini 变成 NAT 路由器，正好允许局域网电脑通过它访问互联网，与当前要求相反。

## 9. 代理注意事项

当前参考主机使用 PAC 代理 `http://localhost:1089/proxy.pac`。目标 Mac mini 是否需要代理仍需现场确认。

如果江苏省监测技能竞赛在线答题系统运行在 Docker 中，容器通常不会自动继承 macOS 桌面 PAC 配置。后续要明确配置供应商 API 的代理出口，并将以下地址加入 `NO_PROXY`：

```text
127.0.0.1,localhost,10.20.0.0/24
```

## 10. 连通性验收

### 10.1 Mac mini 检查两个网段

```bash
route -n get default
ping -c 3 192.168.1.1
curl -I https://api.siliconflow.cn
ping -c 3 10.20.0.10
```

默认路由必须经过 Wi-Fi，而不是以太网。

### 10.2 临时启动局域网服务

```bash
python3 -m http.server 4000 --bind 10.20.0.1
```

### 10.3 客户端验收

```bash
ping 10.20.0.1
curl http://10.20.0.1:4000/
curl --connect-timeout 5 https://example.com
```

验收标准：

1. 客户端能访问 `10.20.0.1:4000`。
2. 客户端不能访问互联网，最后一条 `curl` 必须失败。
3. Mac mini 自身能访问互联网模型 API。
4. Mac mini 的 IPv4 和 IPv6 转发值均为 `0`。
5. 上网主路由器没有连接到独立交换机。

测试结束后停止临时 HTTP 服务。

## 11. 当前结论

采用以下拓扑：

```text
Mac mini Wi-Fi -> 上网路由器 -> Internet
Mac mini Ethernet -> 独立交换机/AP -> 无互联网客户端
```

Mac mini 利用 Wi-Fi 和有线以太网两个网络接口连接两个网段，但不在两个网段之间进行通用转发。局域网电脑只能调用 Mac mini 上的江苏省监测技能竞赛在线答题系统，由该系统代表它们访问模型供应商。
